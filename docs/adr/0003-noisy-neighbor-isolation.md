# 0003. Fair Queue と送信先ごとの同時送信数の上限

## 状況

全テナントでキューとワーカーを共有します。応答しない送信先が処理枠を占有すると、正常な送信先への配信まで遅れます。

## 決定

- SQS 標準キューの `MessageGroupId` にテナント ID を指定し、Fair Queue を使う
- ワーカーのタスク内で、送信先ごとの同時送信数を制限する
- 上限を超えた配信は、送信回数を増やさずに待機させる

## 結果

- 他のテナントと、同じテナントの他の送信先の両方を保護できる
- 上限はタスク単位なので、全体の同時送信数は上限 × タスク数になる
- Fair Queue は AWS 固有なので、`internal/adapters/aws` に閉じ込める。送信数の上限は `core` に置く
