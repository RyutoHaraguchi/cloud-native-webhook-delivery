# 0004. 検査済み IP への固定接続による SSRF 対策

## 状況

利用者が登録した URL にワーカーが接続するので、内部ネットワークへのアクセスに悪用される恐れがあります。DNS 解決後に IP を検査するだけでは、接続時の再解決で内部 IP に差し替えられます（DNS リバインディング）。

## 決定

- 配信ごとに DNS を 1 回解決し、すべての IP を検査して、その IP にのみ接続する
- HTTPS のみ許可し、リダイレクトは追わない
- 検証用の例外は、環境変数で指定したホストの完全一致のみとする

## 結果

- 内部アドレスの登録、DNS の差し替え、リダイレクトによる迂回を防げる
- HTTP クライアントの接続処理に手を加える必要がある
- 例外の設定はテナントから変更できない
